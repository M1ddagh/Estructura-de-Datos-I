# Unidad I · Modelos de Representación de Datos

##Objetivo

Comprender las diferentes formas en que los datos pueden ser representados y organizados en un programa, para seleccionar la estructura más adecuada según cada problema.

##Resumen

En esta unidad se estudiaron los principales modelos de representación de datos. Se abordó el concepto de **Tipo de Dato Abstracto (ADT)**, que permite definir las operaciones de una estructura sin depender de su implementación interna.

También se analizaron las diferencias entre los **datos estáticos**, que poseen un tamaño fijo y permiten un acceso rápido, y los **datos dinámicos**, que pueden crecer o reducirse durante la ejecución del programa.

Finalmente, se trabajó con **datos simulados** para realizar pruebas y con **datos persistentes**, que permiten almacenar información en archivos para conservarla después de cerrar el programa.


## Temas principales

* Tipos de Datos Abstractos (ADT).
* Representación estática de datos.
* Representación dinámica de datos.
* Datos simulados.
* Persistencia de datos mediante archivos.

##Contenido

Esta unidad contiene ejemplos y ejercicios relacionados con los diferentes modelos de representación y organización de datos.
